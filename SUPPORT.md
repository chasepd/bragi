# Support

Bragi is maintained on a best-effort basis.

- Use GitHub Issues for reproducible defects and focused feature requests.
- Consult `README.md`, `docs/troubleshooting.md`, and
  `docs/docker-compose.md` before filing a setup question.
- Use the private process in `SECURITY.md` for vulnerabilities.

When asking for help, include the Bragi version or commit, operating system,
deployment method, and sanitized logs. Never post API keys, passwords,
database files, save exports, private roleplay content, or identifying details.
