# Security Policy

## Supported Versions

Bragi is pre-1.0. Security fixes are made on the latest `main` branch and are
included in the next release. Older snapshots are not supported.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting form:

https://github.com/chasepd/bragi/security/advisories/new

Include affected versions or commits, reproduction steps, impact, and any
suggested mitigation. Do not include real API keys, passwords, save data,
roleplay transcripts, or other personal information. You can expect an initial
acknowledgement within seven days.

Bragi is designed for authenticated use on a trusted private LAN. Reports that
depend on public-Internet exposure are still welcome, but the documented trust
boundary and deployment warning in `README.md` will be considered when
assessing severity.
