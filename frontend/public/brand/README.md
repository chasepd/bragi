# Bragi Brand Assets

`bragi-chronicle-hero.webp` is a decorative wide background generated from the
canonical Bragi portrait reference. It is used only behind authentication and
the desktop workbench atmosphere; all interface text and controls remain live
HTML.

The artwork was generated locally through the built-in image generation flow
and optimized to WebP before being added to the frontend. No provider keys or
raw request payloads are stored in the repository.
