# Bragi Brand Assets

`bragi-chronicle-hero.webp` is a decorative wide background generated from an
AI-generated portrait reference. Both generations used AI-generated imagery,
with no human-authored reference artwork. The project therefore treats the
result as non-copyrightable and freely reusable. The repository's MIT License
also grants permission to use, copy, modify, and distribute the artwork to the
extent copyright applies in a jurisdiction.

The image is used only behind authentication and for the desktop workbench
atmosphere; all interface text and controls remain live HTML.

The artwork was generated locally through the built-in image generation flow
and optimized to WebP before being added to the frontend. No provider keys or
raw request payloads are stored in the repository.
